## ⚠️ Xavfsizlik eslatmalari

Saqlangan xabarlar orasida quyidagilar ham bor edi — bular **foydali emas, balki xavfli**, shuning uchun katalogга kiritilmadi yoki alohida belgilandi:

- **"OpenBudget / ovoz berib pul ishlash" botlari** — bu klassik firibgarlik (scam) sxemasi. Hech qachon bu botlarga karta/telefon ma'lumotini bermang.
- **`c1641.coresuz1.ru/spy.php?token=...`** turidagi havola — bu kuzatuv/zararli havola bo'lishi mumkin. Ochmang.
- **BreachForms leak havolalari** — noqonuniy ma'lumot bazalariga havola; yuklash huquqiy xavf tug'diradi.
- **Crack qilingan tijoriy dasturlar** (Burp Pro, Acunetix, IDA Pro, Cobalt Strike, Core Impact, Invicti) — katalogda nomi ko'rsatilgan, lekin crack parollari va yo'riqnomalari kiritilmadi. Bular litsenziyasiz tarqatilgani uchun huquqiy xavf bor; imkon qadar bepul/open-source muqobillardan foydalaning.
